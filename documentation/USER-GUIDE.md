# User guide

## Free public demo

1. Open the demo. Select EN, RW or FR using the language selector.
2. View the overview: savings, outstanding loans, member count and recent activity.
3. Choose a fictional Member profile. Open Contributions and submit a fictional payment notice. Pending notices should not count as confirmed savings.
4. Choose the Treasurer profile, find the pending notice and approve it to simulate receipt of external money.
5. As a Member, open Loans and submit an application. Switch to Chairperson to review it, then Treasurer for any available disbursement action.
6. Explore Members, Reports and Group settings. Download a sample CSV if desired.
7. Reset the demo when finished. Everything remains fictional and browser-local.

Do not enter real personal, account or financial information into the public demonstration. Role switching and browser-local storage are intentional simulation features.

## Full website and Android app

Register with a phone number and a password of 12-128 characters. No phone ownership verification or SMS service is connected. Create a group or join with an invitation. A group can use flat or reducing-balance interest. Financial changes have role checks, confirmation and audit records on the server.

Additional full-app tools include private receipts, expenses, savings withdrawals, balance reconciliation, linked corrections, contribution schedules, announcements, sessions and local-code recovery. These are not all present in the older static demo.

See [website setup](../e-kimina/README.md) and [mobile setup](../e-kimina-mobile/README.md) for exact launch instructions. The existing installed APK requires the local server plus USB forwarding; use Connect-Android-APK.cmd after reconnecting the cable.
