# Fictional demo access

The free public demo does not require login, a password, an account or an SMS code. Open the published link and use the Try a role selector at the top of the workspace.

| Fictional profile | Role | Suggested test |
| --- | --- | --- |
| Aline Uwase | Treasurer | Review an external payment notice |
| Eric Mugisha | Member | Submit a contribution or request a loan |
| Jean Niyonzima | Chairperson | Review a loan application |
| Grace Mukamana | Secretary | Explore group records |

All people, contacts, amounts and transactions in this demo are invented. Do not send money or contact sample numbers. Role switching intentionally needs no credentials. Browser storage persists changes only on the current browser. Changes are not synchronized with the mobile APK, another browser or another person. Reset demo restores the fictional starting state.

For backend testing, create fictional accounts on a separate test database through the full registration flow. Never publish real account passwords or reuse a personal password as a judge credential. There are no public hosted backend accounts in this static deployment.
